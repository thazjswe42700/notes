## 🎨 PPTist - 在线演示文稿编辑器完整部署指南

### 项目介绍

PPTist 是一款功能强大的网页版演示文稿应用，它将 PowerPoint 的核心功能完全搬到了浏览器中。基于 Vue 3.x 和 TypeScript 构建，无需依赖重型 UI 组件库，这使得它的扩展性和定制化能力都相当出色。

这款工具支持丰富的元素类型——文本、图片、形状、线条、图表、表格、视频、音频和公式等。你可以直接在浏览器中进行完整的幻灯片编辑和演示，享受接近桌面应用的流畅体验。此外，PPTist 还集成了 AI 生成 PPT 的能力，支持导出为 PPTX、PDF、图片等多种格式，甚至在移动设备上也能进行基础编辑。

项目地址：[点我跳转](https://github.com/pipipi-pikachu/PPTist)

### 部署安装

如需在公网环境中访问你的 PPTist 实例，建议配置内网穿透服务。推荐使用 [帕斯内网穿透](https://passnat.com) —— 一站式解决远程访问需求，支持全平台快速上手。具体操作可参考 [帕斯内网穿透全平台快速指南](https://www.passnat.com/posts/p)，让你随时随地都能访问自己的演示文稿编辑器。

#### 使用 Docker 快速启动

PPTist 项目本身是一个前端应用，最简便的部署方式是利用 Docker 容器化技术。

**步骤一：获取镜像**

打开你的 NAS 设备（如飞牛 NAS、群晖等）或本地 Docker 环境，找到镜像管理界面。

选择 **本地镜像** → **添加镜像** → **从 URL 添加**，在镜像地址栏填入：

```
node:18-alpine
```

等待镜像下载完成。

**步骤二：创建容器**

镜像下载完成后，点击启动按钮。在容器配置界面中：

容器名称：自定义名称，如 'pptist'

勾选开机自动启动：确保 NAS 重启后服务自动恢复

**步骤三：端口映射配置**

这一步很关键。PPTist 默认运行在容器内的 **5173 端口**。

在端口映射设置中，将容器端口 5173 映射到主机端口（可以是 5173 或任意未被占用的端口，比如 8080）。如果遇到端口被占用的提示，只需修改主机端口号即可，容器内的端口保持不变。

**步骤四：存储配置**

PPTist 是一个纯前端应用，不需要特殊的数据持久化目录。如果你想保存编辑的演示文稿，可以选择挂载一个本地文件夹用于存储导出的文件。

**步骤五：环境变量设置**

PPTist 基础版本不需要额外的环境变量配置，保持默认即可。如果后续需要集成 AI PPT 功能或自定义后端服务，可根据需要添加相关变量。

**步骤六：启动服务**

完成上述配置后，点击启动按钮。容器启动后，在浏览器中访问：

```
http://你的NAS地址:5173
```

或者如果你映射到了其他端口（比如 8080）：

```
http://你的NAS地址:8080
```

稍等片刻，PPTist 的编辑界面就会加载完成。你现在可以开始创建、编辑和演示你的幻灯片了。
