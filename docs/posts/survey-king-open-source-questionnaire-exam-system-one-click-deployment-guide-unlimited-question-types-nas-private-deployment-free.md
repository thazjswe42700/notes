## SurveyKing 问卷考试系统 - 一键部署指南

#### 项目介绍

**卷王（SurveyKing）** 是一个功能强大的开源问卷调查与在线考试系统，采用现代化技术栈构建。它支持超过20种丰富的题型（包括填空、选择、下拉、级联、矩阵、分页、签名、题组、文件上传等），提供了完整的问卷管理、数据分析和考试评分功能。

相比商业问卷产品，卷王具有更强大的逻辑设置能力、自动计算功能、自定义校验和导出选项。无论是企业调研、学校考试、员工培训还是市场问卷，卷王都能轻松胜任。最关键的是——它完全免费且支持私有部署，让你的数据掌握在自己手中。

项目地址：[点我跳转](https://github.com/javahuang/SurveyKing)

#### 部署安装

若需要在公网环境中访问卷王，建议配置内网穿透工具。推荐使用 [帕斯内网穿透](https://passnat.com)，先完成账号注册以备后用。详细的配置步骤可参考 [全平台内网穿透上手指南](https://www.passnat.com/posts/p)，几分钟即可完成配置。

##### 最快速部署方案

卷王提供了极其简洁的Docker一键部署方案，无需任何复杂配置，一条命令即可启动：

```bash
docker run -p 1991:1991 surveyking/surveyking
```

执行上述命令后，等待镜像下载和容器启动完成。

##### 访问应用

部署完成后，打开浏览器访问：

```
http://你的IP地址:1991
```

使用默认账号登录：

**账号**：admin

**密码**：123456

至此，卷王问卷系统已成功部署并可正常使用！

##### 端口说明

**1991** 是卷王的默认服务端口

如果你的服务器上已有其他应用占用1991端口，可将命令修改为：docker run -p 9999:1991 surveyking/surveyking（将9999替换为你想使用的空闲端口）

容器内部始终运行在1991端口，修改的只是外部访问的端口映射

##### NAS设备部署

如果你使用飞牛NAS或其他NAS设备，操作步骤如下：

打开NAS管理界面，进入**本地镜像**模块

点击**添加镜像** → **从URL添加**

镜像地址填写：surveyking/surveyking

等待镜像下载完成后，点击**启动**按钮

在容器配置中，设置**端口映射**：容器端口1991映射到主机端口1991（或其他可用端口）

勾选**开机自动启动**选项，确保系统重启后自动运行

完成配置后点击启动，即可通过 http://NAS\_IP:1991 访问卷王系统
