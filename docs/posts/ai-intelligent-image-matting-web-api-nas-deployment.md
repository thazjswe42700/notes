## 项目介绍

Image Matting 是一款强大的在线图像抠图工具，基于深度学习技术打造。它提供了Web界面和API接口，支持通过文件上传或URL直接处理图像，能够智能识别并分离前景主体。项目内置了两种先进的AI模型——通用模型和人物专用模型，可以精准地为各类图像生成透明背景的抠图结果和对应的掩码图。无论是证件照处理、产品图美化还是创意设计，都能轻松搞定。

## 部署安装

如果需要在外网也能访问项目，建议配置内网穿透服务。可以前往 [帕斯内网穿透](https://passnat.com) 注册账号，然后参考 [这份完整上手指南](https://www.passnat.com/posts/p) 来快速配置，让你在任何地方都能远程使用这个抠图工具。

### Docker 一键启动

打开飞牛 NAS 或其他 NAS 设备的管理界面。

点击 **本地镜像** - **添加镜像** - **从 URL 添加**。

在镜像地址栏填入：ihmily/image-matting:latest

等待镜像下载完成后，点击启动按钮启动容器。

勾选 **开机自动启动** 后进入下一步。

**端口映射设置**

在这一步需要配置端口映射。将容器内的 **8000 端口** 映射到宿主机的 8000 端口（或其他未被占用的端口）。如果你的 NAS 上 8000 端口已被占用，可以修改为其他端口号，比如 8001、8002 等，但容器内部的端口保持 8000 不变。

**存储位置设置**

该应用会自动生成处理结果和缓存文件，建议在 NAS 上创建一个专用文件夹（如 /mnt/image-matting）用于存储处理过的图像和模型缓存，这样可以保证数据持久化。

**环境变量设置**

该项目无需特殊环境变量配置，直接下一步启动即可。

配置完成后点击启动，稍等片刻即可通过浏览器访问 http://你的NAS\_IP:8000 来使用在线抠图功能。

到这里部署就完成了！你现在可以上传图片进行智能抠图处理，支持选择不同的AI模型获得最佳效果。
