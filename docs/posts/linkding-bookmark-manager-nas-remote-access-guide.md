## 项目介绍

Linkding 是一个自己部署的书签管理器。浏览器书签栏塞不下、换一台电脑就找不着，它就是来解决这个的：网址收进来，打上标签，以后按标签筛或者直接全文搜。

每条书签都能加一段 Markdown 笔记，还能存一份网页快照 —— 哪天原网页没了，存下来的那份还在。攒到几百上千条也不慌，搜索是对标题、描述、笔记一起搜的。

它基于 Django，很轻，一个容器就够，数据库用内置的 SQLite。官方有 Firefox 和 Chrome 扩展，页面上按一下就把当前标签页收进来；也支持装成 PWA，手机上当独立应用用。书签、标签、快照全落在你自己 NAS 的一个目录里。

项目地址：[点我跳转](https://github.com/sissbruecker/linkding)

## 部署安装

装在自己的 NAS 上之后，它默认只能在家里的网络里打开 —— 可书签库偏偏是那种「在公司想起来家里存过一条」的东西，只能在家用就废了一半。我家是移动宽带，没有公网 IP，所以用 [帕斯内网穿透](https://passnat.com) 把它开放到公网，飞牛的应用中心里就能直接装到插件，不用另外找工具。下面这套流程在飞牛 NAS 上从头到尾走一遍。

### 第一步：准备编排文件

下面这份编排可以直接用，需要你动的只有最后一行的口令。

```yaml
services:
  linkding:
    image: sissbruecker/linkding:1.46.2
    container_name: linkding
    ports:
      # 左边 9090 是 NAS 上对外的端口，浏览器敲它；右边 9090 是容器里的
      - '9090:9090'
    volumes:
      # 书签、标签、网页快照都存这儿，删容器不丢数据
      - ./data:/etc/linkding/data
    environment:
      # 管理员账号在这儿直接建，不用再进容器敲命令
      LD_SUPERUSER_NAME: admin
      LD_SUPERUSER_PASSWORD: 换成你自己的口令
    restart: unless-stopped
```

端口：冒号左边的 9090 是 NAS 上对外的端口，浏览器敲它，建隧道时也填它；右边的 9090 是容器内部的端口，不要动。左边被别的容器占了就换一个没用过的，比如写成 '9091:9090'。

数据目录：./data 里是书签、标签和网页快照，相对编排文件所在的目录，所以整个项目文件夹拷走就是一份完整备份，容器删了重建数据也还在。

管理员账号：最后那两行是重点 —— 用户名和口令在编排里填好，容器一起来管理员就建好了，不用再进容器敲命令。LD\_SUPERUSER\_PASSWORD 那一行一定要换成你自己的口令，别把示例文字原样留着就开到公网上去。

镜像这一行写的是 1.46.2，跟视频里演的是同一个版本，照抄就能复现片子里的界面；上游出了新版本想跟，把这一行的版本号换掉再重新构建一次即可。

### 第二步：在飞牛上建 Compose 项目

回飞牛桌面打开 Docker，切到上面的 Compose，点新增项目。项目名称填 linkding。

路径这一栏点右边的图标打开选择器，挑一个空文件夹选中；没有合适的就当场新建一个，名字随便起。这个文件夹以后就是这个项目的家，编排文件和上面那个 data 目录都会落在它里面。

来源选「创建 docker-compose.yml」，把上面那份编排整段贴进去。勾上「创建项目后立即启动」，点确认。记住 9090 这个端口，下一步建隧道要填它。

### 第三步：用内网穿透开放到公网

容器跑起来之后，先别急着在内网点来点去 —— 下一步直接把它开放到公网，后面登录、存书签、拿接口令牌全都在公网地址上做，能省掉一轮返工。

在飞牛的应用中心里搜 PassNAT，装上，账号登一次。打开插件，点加号建隧道：名字随便起；接入节点和传输协议都留默认；本地 IP 这一栏不用动，留它默认的 127.0.0.1，不用去查自己 NAS 的局域网地址；本地端口填上面那个 9090。

建好之后在列表里点开这条隧道的详情，最左边那个电源键点一下，公网地址就出来了，状态转成运行中。面板上那个「IP:端口」就是在外面要用的地址，后面所有操作都用它。

### 第四步：在公网地址上登进去

用刚拿到的公网地址打开，拿编排里设的那个用户名和口令登进去 —— 账号在容器启动时就建好了，不用再注册。

## 怎么用

存一条试试：点右上角的加号，把网址粘上去，它会自己把标题和描述抓回来；打一个标签，保存。在外面存的这一条，家里那台打开立刻就有了 —— 东西本来就只有一份，存在 NAS 上。

左边点标签就能筛，几百条也好找；上面的搜索框是对标题、描述和笔记一起搜的。每条书签点开可以加 Markdown 笔记，也可以标成「稍后读」，读完再取消。

设置页里有浏览器扩展和接口令牌两样东西。扩展装上之后，在任意网页按一下就收进来，比回来手动粘网址顺手得多。令牌是给第三方工具调接口用的，注意它只显示这一次，建完当场复制走，关掉页面就看不到了。

## 一些使用上的细节

数据全在项目文件夹的 data 目录里。想搬到另一台机器，把整个文件夹拷过去、用同样的编排起一个容器，打开还是原来那些书签。

网页快照分两种：存到本地和存到互联网档案馆，在设置里可以分别打开。存本地的那份会占盘，书签多了之后留意一下 NAS 的空间。

暂时不想让外面访问的话，去 PassNAT 插件里把那条隧道的电源关掉就行，内网照常用，容器不用动。
