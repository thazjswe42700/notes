## Odoo - 开源企业管理系统完整部署指南

### 项目介绍

Odoo 是一套功能强大的开源商业应用套件，专为企业级用户设计。它集成了客户关系管理（CRM）、电商平台、库存管理、项目管理、财务会计、销售点系统、人力资源、市场营销、生产制造等多个模块。无论你是小型创业公司还是大型企业，Odoo 都能提供完整的ERP解决方案。

该系统采用网页端架构，开箱即用，支持模块化安装，让你可以根据实际需求灵活选择功能。所有应用无缝集成，为你的业务流程提供统一的管理平台。

项目地址：[点我跳转](https://github.com/odoo/odoo)

### 部署安装

如果需要在外网也能访问你的 Odoo 系统，建议配置内网穿透服务。推荐使用 [帕斯内网穿透](https://passnat.com) 服务，先注册好账号备用。具体的详细操作步骤可以参考 [全平台内网穿透快速入门指南](https://www.passnat.com/posts/p)。

#### 使用 Docker 快速部署

打开你的 NAS 设备或本地 Docker 环境，点击'本地镜像'- '添加镜像'- '从 URL 添加'。

在镜像地址栏填入：odoo:latest

等待镜像下载完成后，点击启动按钮创建容器。

**端口映射配置：**

容器内部端口：8069（Odoo 主服务端口）

宿主机端口：可设置为 8069 或其他未被占用的端口

如果提示端口冲突，只需修改宿主机端口号即可，容器内部端口保持不变。

**存储配置：**

Odoo 需要持久化存储数据库和附件文件。建议创建以下目录映射：

/var/lib/odoo - 用于存储 Odoo 数据和配置

/mnt/extra-addons - 用于存储自定义模块（可选）

**环境变量设置（可选）：**

如无特殊需求，环境变量无需配置。Odoo 会使用默认设置自动初始化。

勾选'开机自动启动'后，点击下一步启动容器。

创建成功后，打开浏览器访问 http://你的IP:8069，即可进入 Odoo 初始化界面。

首次访问时，系统会引导你创建数据库和管理员账户，按照提示操作即可完成部署。

### 总结

通过以上步骤，你就能在几分钟内快速部署一套完整的企业管理系统。Odoo 强大的功能和灵活的扩展性，能够满足各种业务需求。祝你使用愉快！
