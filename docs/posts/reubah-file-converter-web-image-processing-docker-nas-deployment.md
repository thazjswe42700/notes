## 项目介绍

Reubah 是一个开源的图片和文档处理工具，跑在浏览器里：打开网页，把文件拖进去，选好格式和尺寸，点一下处理，结果直接下载。不用在每台电脑上装一堆转换软件，NAS 装一次，家里谁的浏览器都能用。

它把三件事放在同一页的三个标签里：

**图片处理**：JPEG、PNG、WebP、GIF、BMP、HEIC 互转，也能直接输出 PDF；带四档质量（无损、90%、75%、60%），可以按宽高缩放，三种缩放方式分别是保持比例、裁剪填满、强制拉伸。

**文档处理**：PDF、Word（docx / doc）、ODT、RTF、TXT 之间互转，常见用法是把 PDF 转成 Word 继续改，或者把文档转成 PDF 发出去。

**批量处理**：一次拖进多张图，可以逐张处理逐个下载，也可以合并成一份 PDF，选 A4 / Letter / Legal、横竖方向、每页放 1 / 2 / 4 张。

文件大小上限 32MB。处理在 NAS 上完成，不经过第三方服务，处理完的成品由浏览器直接下载，服务器上不留存。

项目地址：[点我跳转](https://github.com/dendianugerah/reubah)

## 部署安装

只要能跑 Docker 的 NAS 都能装，下面用飞牛 NAS 演示：先用 [帕斯内网穿透](https://passnat.com) 拿到一个公网地址，再把 Reubah 用 Docker Compose 装起来。先穿透、后部署，装完直接用公网地址打开，在外面用手机也能把图片转一下、把 PDF 转成 Word。

### 一、先用帕斯内网穿透拿到公网地址

飞牛的「应用中心」里搜 PassNAT，装上这个穿透插件，打开它，点「创建隧道」。隧道名字随便起（不超过 12 个字符），接入节点和传输协议留默认，本地 IP 留默认的 127.0.0.1，本地端口填 8090（就是下面编排里冒号左边那个端口）。

建好之后点开这条隧道，按一下电源，状态变成运行中，详情里就能看到分配好的公网地址（形如 IP:端口），先记下来。

不是飞牛的系统，PassNAT 文档的「连接使用」里有其他系统的连接教程：[点我跳转](https://doc.passnat.com/docs/category/%E8%BF%9E%E6%8E%A5%E4%BD%BF%E7%94%A8)。

### 二、新建 Compose 项目

打开飞牛的「Docker」应用，切到「Compose」标签，点右上角的新增项目。项目名称填 reubah，路径在「我的文件」下面挑一个空文件夹，没有就当场新建一个。来源选「创建 docker-compose.yml」，把下面这段整个贴进去：

```yaml
services:
  reubah:
    image: ghcr.io/dendianugerah/reubah:latest
    container_name: reubah
    ports:
      - "8090:8081"
    restart: unless-stopped
```

这段编排没有要改的地方，直接能用。唯一值得知道的是端口：**冒号左边 8090 是 NAS 上对外开放的端口**，被占用的话换成别的数字，隧道里的本地端口也跟着改；**冒号右边 8081 是容器里程序自己监听的端口**，这个不要动——Reubah 默认监听 8081，不是常见的 8080，写错了页面打不开。

它没有数据库、没有登录、也不需要挂卷：处理是即时的，成品由浏览器下载，所以不用准备存储目录，重启容器也不丢任何东西（本来就没存东西）。

勾上「创建项目后立即启动」，镜像下完就起来了，总共几十 MB，很快。

### 三、图片处理：转换、缩放、压缩

用公网地址打开，默认就在「图片处理」这个标签。把图片拖进虚线框，或者点框里的选文件按钮，框会变绿并显示文件名和大小。

**输出格式**在下拉里选：照片转 JPEG 体积小，截图和图标转 PNG 不失真，要更小的体积选 WebP，需要打印或者归档就选 PDF。

**质量**四档：Lossless 无损、High 90%、Medium 75%、Low 60%。日常照片 75% 到 90% 已经看不出差别，实测一张 2400×1600 的 PNG 转成 WebP 90%，从 0.05MB 降到 15KB 左右，缩到 1200 宽之后还会更小。

**缩放**填宽度或高度其中一项就行，另一项留空，默认「Fit」会按比例算；「Fill」是裁剪填满指定尺寸，「Stretch」是强行拉伸，容易变形，一般不用。

下面的优化开关勾上会再做一轮体积优化，不改变尺寸。点最下面那个紫色主按钮，几秒后结果区就出现了：预览图、成品大小、右边的「Download Image」按钮，点一下存到本地。

注意「Remove Background」标着 Coming Soon，现在还不能用，别在这个上面等。

### 四、文档转换：PDF 和 Word 互转

切到「文档处理」标签，选文档拖进去。输出格式有六种：PDF、Word（docx）、Word 97-2003（doc）、ODT、纯文本、RTF。

最常用的是两个方向：PDF 转 Word，拿到能改的稿子；Word 转 PDF，发出去别人打开不会跑版。实测一页 A4 的中文 PDF 转成 docx，标题、段落、表格都在，中文没有乱码。

点转换按钮，它会显示转换中，完成后浏览器直接下载成品，文件名是原名后面加 \_converted，不会覆盖你上传的原文件。

需要说明的是：这是格式转换，不是排版还原。原文档里特别复杂的版式（多栏、文本框、艺术字）转过来会有出入，转完自己翻一遍再发。

### 五、批量处理：多张图一次转完

切到「批量处理」标签，一次选多张图。上面选处理模式：

**逐张处理那一项**：每张单独处理，按统一设置输出，逐个下载。适合把一批照片统一缩到同一个宽度、或者统一转成 WebP。

**合并成 PDF 那一项**：把所有图片按顺序合成一份 PDF，可以选纸张大小、横竖方向、每页放几张。适合把手机拍的票据、作业、资料合成一份发出去。

宽高同样可以统一填，留空就按原图。选好格式点最下面的主按钮即可。

### 几点说明

**没有登录。** Reubah 本身没有账号体系，谁能打开这个地址谁就能用。公网地址只发给自家人，用完可以在插件里把隧道关掉，下次要用再开。

**文件不留存。** 处理在 NAS 上完成，成品下载到浏览器，服务器不保存上传的文件。真要留档，记得自己把成品存好。

**32MB 上限。** 单文件超过 32MB 会被拒绝，手机拍的视频和超大 RAW 文件不在它的适用范围里。

**升级。** 镜像用的是 latest，到 Docker 里重新拉取镜像、重启项目即可；它没有数据卷，升级不涉及迁移。

**明文 HTTP 访问。** 内网穿透给的是 http 地址，这个工具本身不需要 HTTPS 才能用；但因为它没有登录，公网地址别到处发。
