# I Hate Money：NAS 上用 Docker 自建共同开销记账（AA / 分摊 / 结算）

> 几个人出去玩、合租、一起吃饭，钱怎么分清楚。自托管、数据在自己 NAS 上、手机浏览器就能记账，记完自动给出「谁付给谁多少」的结算建议。

## 这个项目解决什么问题

I Hate Money 是一个自托管的共同开销记账工具。核心模型很简单：

1. 建一个**账目**（一次旅行、一个合租屋、一个饭局）
2. 把一起花钱的人加进这个账目（对方**不需要注册账号**）
3. 每花一笔记一条：**谁付的钱、花了多少、这笔钱是替哪几个人付的**
4. 系统按勾选的成员自动分摊，账目页实时显示每个人的余额
5. 点「解决」，直接给出「谁付给谁多少」的最小转账方案

它只算账，不接支付渠道，转账仍然用微信/银行/现金，转完自己在页面上登记结清。

官方仓库：<https://github.com/spiral-project/ihatemoney>

## 前置要求

| 项 | 要求 |
|---|---|
| 硬件 | 能跑 Docker 的 NAS（本文在飞牛 fnOS 实测） |
| 内存 | 512 MB 足够，单容器应用 |
| 数据库 | 默认 SQLite，**不需要**另外装数据库 |
| 外网访问 | 可选。需要出门记账时，用内网穿透给一个公网地址 |

## 快速开始

在 NAS 的 Docker → Compose → 新增项目，来源选「创建 docker-compose.yml」，粘贴：

```yaml
services:
  ihatemoney:
    image: ihatemoney/ihatemoney:latest
    restart: unless-stopped
    ports:
      - "8000:8000"
    environment:
      SECRET_KEY: change-me-to-a-random-string
      SESSION_COOKIE_SECURE: "False"
    volumes:
      - ./data:/database
```

启动前**必须改一处**：

- `SECRET_KEY`：换成你自己的随机字符串，越长越好。它用于签名登录状态。改完已登录的浏览器需要重新登录，账目数据不受影响。

启动后浏览器打开 `http://NAS地址:8000`，右上角语言菜单选「中文（简体）」。

## 配置项说明

| 变量 | 默认值 | 说明 |
|---|---|---|
| `SECRET_KEY` | 无（必填） | 登录状态签名密钥，务必替换示例值 |
| `SESSION_COOKIE_SECURE` | `"False"` | 用 http 地址访问时必须保持 `"False"`，否则登录状态写不进去；将来配了 HTTPS 再改 `"True"` |
| 端口映射 | `8000:8000` | 左侧被占用就换一个数字，后续访问和内网穿透都用新端口 |
| 数据卷 | `./data:/database` | SQLite 数据库文件在这里，**备份这个目录就够了** |

想换成 PostgreSQL / MySQL：改 `SQLALCHEMY_DATABASE_URI`，写法见官方文档。

## 第一次使用

1. **新建账目**：填账目名称（如「周末露营」）、共享密钥（自己定）、邮箱。邮箱只用于提醒邮件，没配 SMTP 只会提示一句发送失败，不影响使用。
2. **加成员**：账目页右上角「添加」，填名字即可，对方不用注册。
3. **记账**：点「添加新帐单」，填日期、事由、付款人、金额；下方「成员？」勾选这笔钱替谁付——全勾就是全体均分，只勾两人就这两人分。
4. **看结算**：导航栏「解决」，给出最小转账方案；「统计」页看每人付款/支出和按月汇总。
5. **邀请别人**：账目页左侧「邀请别人」生成邀请链接和二维码，发群里点开就能记账，不用再输共享密钥。

金额输入框支持算式，比如 `(18+36.2)/3` 会直接算出结果。

## 常见问题

**Q：别人要注册账号吗？**
不用。加成员只填名字；知道「账目名称 + 共享密钥」的人，或者拿到邀请链接的人，就能进这个账目。

**Q：数据存在哪？怎么备份？**
`./data` 目录里的 SQLite 文件。备份这个目录即可；换机器时整个目录带走。

**Q：出门在外怎么记？**
配一条内网穿透隧道（本文用帕斯内网穿透）：本地 IP `127.0.0.1`，本地端口填 compose 里映射的端口（默认 `8000`），协议默认 TCP。建好后点开隧道 → 开机 → 状态「运行中」，详情里的地址就是公网入口。

**Q：用 http 公网地址登录后一直退回登录页？**
`SESSION_COOKIE_SECURE` 还是 `"True"`。用 http 访问必须设成 `"False"`。

**Q：它会不会替我转账？**
不会。结算页只给建议，转账自己用微信/银行/现金，转完在页面上登记结清。系统不接支付渠道。

**Q：怎么升级？**
镜像标签是 `latest`：先备份 `./data`，再在 Docker 里重新拉取镜像、重启项目。

## 安全与暴露面

- 内网穿透给的是 http 地址，**谁拿到地址都能打开登录页**；账目本身还有共享密钥和邀请链接两道门
- 邀请链接等于账目的钥匙，别发到公开的地方
- 要收回某个人的访问权，最稳妥的做法是在「设置」里换掉共享密钥，然后重新发邀请链接
- 用完内网穿透，建议在插件里把隧道关掉
