## 项目介绍

录播姬（BililiveRecorder）是一款专为 B 站直播爱好者打造的开源录制工具。它采用纯 C# 开发，无需依赖 FFmpeg 等外部程序，具有轻量化、高效率的特点。无论你是想保存喜爱主播的精彩直播内容，还是需要长期稳定地监控多个直播间，录播姬都能完美胜任。

这款工具不仅操作简单易上手，只需粘贴直播间链接即可开始录制，而且功能强大。支持自动检测开播状态，直播一开始就自动录制，无需人工守候。更重要的是，它能同时录制多个直播间，占用系统资源极少，即使在低端硬件上也能稳定运行，经过大量用户的长期使用验证，可以 24×7 连续工作。

项目地址： [点我跳转](https://github.com/BililiveRecorder/BililiveRecorder)

## 部署安装

如果你想在家里的 NAS 或其他服务器上部署录播姬，实现随时随地远程访问录制内容，建议配合内网穿透工具使用。推荐使用 [帕斯内网穿透](https://passnat.com)，注册账号后即可轻松将本地服务暴露到互联网。具体的操作步骤可以参考 [内网穿透全平台快速入门指南](https://www.passnat.com/posts/p)，让你快速上手。

### Docker 一键部署

打开你的 NAS 设备或 Docker 管理界面，点击本地镜像 - 添加镜像 - 从 URL 添加。

镜像地址填写：bililive/recorder:latest 或 ghcr.io/bililiverecorder/bililiverecorder:latest

等待镜像下载完成后，点击启动按钮启动容器。

**配置容器参数：**

勾选开机自动启动，确保服务器重启后应用能自动恢复运行。

**端口映射设置：**

录播姬默认使用 5800 端口提供 Web 界面服务。如果你的系统中该端口已被占用，可以修改宿主机的映射端口（例如改为 5801），但容器内部端口保持 5800 不变。端口映射格式为：宿主机端口:5800

**存储配置：**

录播姬需要持久化存储配置文件和录制内容。建议在 NAS 上创建一个专门的文件夹（例如 /mnt/nas/bililive-recorder），然后将其映射到容器内的 /config 目录用于保存配置，映射 /rec 目录用于存储录制的视频文件。这样即使容器重启，你的配置和录制内容也不会丢失。

**环境变量设置：**

录播姬的 Docker 版本通常无需特殊的环境变量配置，保持默认即可正常运行。如果你有特殊需求，可以参考官方文档进行高级配置。

**启动完成：**

容器启动成功后，在浏览器中访问 http://你的NAS地址:5800 即可打开录播姬的 Web 管理界面。界面会显示录制状态、直播间列表等信息，你可以直接在界面上添加想要录制的直播间链接。

到这里部署就完成了。你现在可以开始使用录播姬来自动录制你喜爱的 B 站直播内容。
